# Source and rights contract (draft, version 1)

`manifest.json` records a source and item ID, author/origin, exact external release and checksum when applicable, separate text/translation/audio rights, intended uses, attribution and review evidence. Each medium must explicitly permit the requested use. `analysis` records an internal research use; `pilot_display` is a distinct publication use. A corpus/container license never clears original web text, translation or audio by itself. Approved authored material needs an author agreement reference. BY-SA adaptations need an explicit share-alike decision; NC material is excluded from pilot publication. The validator enforces recorded decisions and does not interpret disputed legal rights.

Run `cd backend && .venv/bin/pytest -q tests/test_content_provenance.py` for contract examples. `app.content_provenance.validate_source_manifest` returns blocking reasons for a selected medium/use; `attribution_lines` produces sorted unique lines only for fully permitted uses. The checked-in entry is intentionally analysis-only and cannot be published. Its author label is a draft attribution, not a signed agreement. P1 publication requires item-level internal source, language and rights review per `docs/learning/solo-development-readiness.md`; historical vocabulary and model generations are not approved by this file.
