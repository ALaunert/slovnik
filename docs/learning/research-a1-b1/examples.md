# Банк кандидатов примеров

Дата: 2026-09-25. **72 модельных кандидата и 3 коротких документальных фрагмента. Пригодных к публикации: 0.** Список служит редакторской работе, не является готовым набором упражнений.

## Поля и происхождение

В каждой группе указан ID темы и различие, которое она должна показать. Каждая строка содержит сербский текст, смысл по-русски, контекст, варианты и права. Следующие общие поля **наследуются каждой строкой E01-A…E36-B**, а не считаются пропущенными:

- `origin = M01/model_draft`; созданы моделью в этом исследовании 2026-09-25. Собственных примеров человека-исследователя в пакете нет. Они не цитаты из G/C/R и не результаты корпусного поиска.
- `translation_origin = M01/model_draft`; русский смысл предложен моделью. Перевод, естественность и допустимые варианты не проверены человеком. Перечень вариантов открыт; отсутствие варианта не означает запрета.
- `script = Latin`, кроме E01-B (Cyrillic, transliteration_of=E01-A). Кириллические записи в поле вариантов E36 — явно производные транслитерации. Исходная модельная запись сохраняется, нормализация не выдаётся за аттестацию.
- `rights_rule_text = не выяснено`; `rights_serbian_example = не выяснено`; `rights_russian_translation = не выяснено`; `rights_audio = не применимо, аудио нет`. Помета **M** в каждой строке ссылается на этот набор, а не на свободную лицензию.
- `naturalness_review = pending`, `meaning_review = pending`, `translation_review = pending`, `rights_review = pending`, `publication = blocked`. Подтверждение конструкции в источнике не подтверждает именно эту фразу.

Варианты оцениваются **под задачу**: другой порядок может сохранить событие и изменить фокус, другой вид — изменить смысл. Неверную по цели, но грамматичную фразу нельзя объявлять неграмматичной. Типичные/предполагаемые ошибки даны отдельно в [карточках](rules.md).
