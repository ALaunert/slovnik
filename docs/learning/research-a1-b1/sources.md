# Реестр источников

Дата доступа для **каждой записи: 2026-09-25**. Веб-страницы и конкретные разделы PDF открыты, если не сказано обратное. «Полный текст доступен» не означает «весь текст прочитан». Страницы — печатные; PDF `#page=` считает листы с 1. На HTML точный локатор — заголовок раздела. Поисковые сниппеты использованы только для поиска.

Виды доказательств: **П** — программа/дескриптор; **О** — описание языка в учебном источнике; **Э** — эмпирическое наблюдение; **К** — контрастивный анализ; **М** — методическая рекомендация; **Р** — ресурс/метаданные. Ни один вид сам по себе не подтверждает все остальные.

## Условия использования: отдельные слои

В каждой записи поле **Права** имеет порядок **правило/авторский текст; сербский пример; русский перевод; аудио**. «Не выяснено» запрещает считать материал готовым к включению в продукт. Для источника без русских переводов или аудио стоит «нет», а для будущего собственного перевода права и авторство устанавливаются заново. Лицензия объяснения не автоматически очищает вложенную чужую цитату/ответ ученика. Ниже фиксируются найденные условия, а не правовое заключение.

- **U:** текст — не выяснено; примеры — не выяснено; русский перевод — не выяснено, готового перевода нет; аудио — нет. Применяется к явно названным ниже записям.
- **NC:** некоммерческая лицензия с указанными ограничениями; коммерческое включение/адаптация не разрешены этим исследованием. Внутренний исследовательский пересказ и ссылка не означают импорт исходного произведения.
- **M01:** модельное происхождение, не выданное за открыто лицензированный контент; все три текстовых слоя требуют редакционного решения, аудио нет.
